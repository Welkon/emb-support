# 正点原子 DP100（DP100 数控电源）

## 官方规格

来源：本机资料包 `~/【正点原子】DP100数控电源/`

- `DP100数控电源用户手册 V1.2.pdf`
- `2，DP100 Digital Power Supply/DP100 Digital Power Supply User manual.pdf`
- `2，DP100 Digital Power Supply/2，PC Software/ATK-DP100 DLL user manual.pdf`
- 固件 `DP100_V1.0.atk` ~ `DP100_V1.4.atk`

关键参数：

| 项目 | 值 |
|---|---|
| 输出 | 0–30.00 V，0–5.000 A，100 W max |
| 设定分辨率 | 10 mV / 1 mA |
| 输入 | DC 5.0–32 V（PD/QC 或直流） |
| 保护 | OVP / OCP / OPP / OTP / REP / UVP |
| OVP 范围 | 0.00–30.50 V |
| OCP 范围 | 0.000–5.050 A |
| 过功率保护 | ≤105.0 W |
| 过温保护 | 50–80 °C |
| 预设组 | 0–9（每组含 V/I/OVP/OCP） |

注意：DP100 是**降压**电源，输入电压必须高于输出电压；资料包明确要求
“DP100 工作在降压模式，需要保证输入电压高于输出电压”。

## 协议

USB HID，VID:PID `2e3c:af01`，64 字节报告：

```
FB op 00 len <data> crc16_lo crc16_hi     # host -> device
FA op 00 len <data> crc16_lo crc16_hi     # device -> host
```

CRC16-Modbus（poly 0xA001，init 0xFFFF）。opcode：

- `0x10` 设备信息（型号、固件、序列号）
- `0x30` 实时遥测（Vin/Vout/Iout/vo_max/温度/输出模式/工作状态）
- `0x35` 设定/输出（子命令 `0x20` + 输出位 + V/I/OVP/OCP，单位 mV/mA）
- `0x40` 系统信息（背光、过温阈值、蜂鸣器）

协议实现参考：

- `lymzzyh/dp100-mcp`（MIT）：完整 opcode、解析和 CRC
- `weigu1/dp100_manipulator`：独立实现的抓包与字段偏移验证

## 本 skill 的行为

- 打开时读取设备信息与 `vo_max`（受输入电压限制），再读取当前预设；
- `set` 会同时下发 V/I/OVP/OCP 和当前输出状态（DP100 协议要求整包写）；
- 电压/电流分别限制在 30 V / 5 A，OVP ≤30.5 V，OCP ≤5.05 A；
- `measure` 读 `0x30` 的 Vout/Iout，功率由 V×I 计算；
- 输出状态读 `out_mode`（1=ON）。

## 未覆盖
